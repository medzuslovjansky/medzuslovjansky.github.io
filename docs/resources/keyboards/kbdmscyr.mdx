# Interslavic Cyrillic keyboard

A proposed keyboard layout for writing Interslavic in Cyrillic script.
The base layer follows the Ukrainian ЙЦУКЕН arrangement; extra Interslavic-specific letters (ј, љ, њ, ћ, ђ, ќ, ѓ, ѣ, ѕ, ы, ъ, ѧ) are reachable through <kbd>AltGr</kbd>.

## Status \{#status}

This layout does not yet ship as a distributable package.
If you are comfortable building Windows `.klc` files, macOS `.bundle`s or XKB snippets, [contributions are welcome on GitHub](https://github.com/medzuslovjansky/keyboards).

## Alternatives \{#alternatives}

Until a dedicated installer exists, the closest built-in layouts are:

- **Ukrainian (standard)** — covers the base layer verbatim.
- **Serbian Cyrillic** — covers ј, љ, њ, ћ, ђ, џ without extra keys.
